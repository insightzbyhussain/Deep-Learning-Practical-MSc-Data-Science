# 📊 Practical 01: Data Preprocessing and Handling (CERN Dataset)

## 🎯 Objective
Perform data cleaning, preprocessing, and transformation on a real-world scientific dataset.

---

## 📂 Dataset
🔗 https://www.kaggle.com/datasets/fedesoriano/cern-electron-collision-data  

---

## ⚙️ Key Steps
- Cleaned column names  
- Handled missing values (M)  
- Removed duplicates  
- Outlier detection & removal (IQR)  
- Feature scaling (StandardScaler)  
- Feature engineering:
  - Total_Energy  
  - Momentum1, Momentum2  
- Correlation analysis  
- File format conversion (CSV, Excel, JSON)  

---

## 📊 Result
- Dataset reduced from ~100k to ~48k after outlier removal  
- Strong relationship observed between energy and momentum  

---

## ▶️ How to Run
1. Download dataset  
2. Place `dielectron.csv` in this folder  
3. Run the notebook
